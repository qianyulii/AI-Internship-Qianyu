第 1 周：AI 基础、Iris、线性回归。至少 6 张图、2 个结果表，报告 ≥1000 字。

四、每周任务详情

第 1 周：AI 认知、工具流、Iris 与线性回归

本周目标

你需要完成 AI 基础认知、工具流搭建、GitHub/Kaggle 初始化，并完成两个基础机器学习项目。

你需要完成

☐注册 GitHub 或 Gitee
☐注册 Kaggle
☐创建个人实习总仓库
☐完成 Iris 鸢尾花分类
☐完成线性回归项目
☐记录 AI 工具使用过程

Iris 项目要求

☐读取 Iris 数据
☐输出数据基本信息
☐绘制类别分布图、特征散点图、相关性热力图
☐使用 Logistic Regression、KNN、Decision Tree
☐输出 Accuracy 和混淆矩阵
☐分析哪个特征对分类最有帮助

线性回归项目要求

☐使用 California Housing 或 Diabetes Regression 数据
☐分析目标变量分布
☐分析特征相关性
☐使用 Linear Regression
☐增加 Ridge 或 Random Forest Regressor 对比
☐输出 MSE、RMSE、MAE、R2
☐绘制真实值 vs 预测值图
